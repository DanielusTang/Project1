My Projects

My portfolio is built on a philosophy of designing for scale and fostering community. Here are some of the projects I have worked on or am currently planning.

Enterprise Food Delivery Management System

Goal: Replace the current Aggie Dining page with a high-concurrency ordering platform.

Key Technologies: Spring Boot, MySQL, Redis (Caching), WebSockets, Spring Task, Nginx.

This end-to-end exercise targets the critical "Hot Key" problem in database management and utilizes a multi-layered caching strategy to ensure speed and consistency. It features real-time order notifications for merchants and automated background jobs for order management.

"Bridge" - Supportive Social Platform

Goal: A platform for students to share supportive prayers and messages for professors, fostering constructive dialogue.

Key Technologies: React (Frontend), Spring Boot (Backend), RBAC (Security).

Motivated by a vision to reduce polarization on campus, this project focuses on designing a safe, well-moderated environment. It involves implementing secure user authentication, role-based access control, and anonymous posting features to ensure privacy and positive engagement.
